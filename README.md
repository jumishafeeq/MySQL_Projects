# MySQL-Project
## Library Management System
A project based on Library Management System, It keeps track of all information about books in the library, their cost, status and total number of books available in the library. 

The Library Management System is a comprehensive database solution designed to manage and streamline the operations of a library. It enables efficient tracking of books, employees, customers, book issuance and returns. The system is structured around six key tables, each serving a specific role to ensure seamless functionality.
